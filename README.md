# rootiest.com

Source for [rootiest.com](https://rootiest.com): the home page of Rootiest Solutions, the catalog of
Rootiest's self-hosted services, its open-source projects, and the Privacy Policy and Terms of Service
that cover all of them.

The site is plain static HTML generated by a small Python script (standard library only). It loads
nothing from other sites: no analytics, fonts, embeds or third-party scripts.

## Layout

| Path | What it is |
|---|---|
| `site/` | The web root. Everything in it is published; nothing outside it is. |
| `site/assets/site.css` | Styles: Catppuccin Latte (light) and Mocha (dark), following the system setting |
| `site/assets/icons.svg` | Icon sprite of [Lucide](https://lucide.dev) glyphs (ISC License) |
| `scripts/sitegen/data/` | The content as data: services, projects, contacts, legal page dates |
| `scripts/sitegen/html/`, `scripts/sitegen/pages/` | HTML building blocks and one module per page |
| `content/legal/` | The Privacy Policy and Terms of Service text, as HTML fragments |
| `scripts/build.py` | Generates the pages into `site/` |
| `scripts/check.py` | Checks `site/`: up to date, no broken links, no third-party scripts |

Every `.html` file in `site/` and `site/sitemap.xml` is generated. Never edit them by hand: edit the
data or content and rebuild. Everything else in `site/` (images, icons, `robots.txt`, `.well-known/`) is
kept by hand.

## Build and check

```sh
python3 scripts/build.py   # regenerate site/
python3 scripts/check.py   # what CI runs
```

Preview locally with any static server, for example `python3 -m http.server -d site 8000`.

## Updating content

- **A service or project:** edit `scripts/sitegen/data/services.py` or `projects.py`, then rebuild.
  Service hostnames and access levels follow the Rootiest infrastructure services map.
- **The legal pages:** edit `content/legal/privacy.html` or `terms.html`. Every `<h2>` needs an `id`
  (the table of contents is built from them). Update the `updated` date in
  `scripts/sitegen/data/legal.py`, then rebuild.
- **A new glyph:** add the Lucide symbol to `site/assets/icons.svg` and refer to it by name.

## Deployment

Pushes to `main` on [git.rootiest.dev](https://git.rootiest.dev/rootiest/rootiest.com) run
`.github/workflows/pages.yml`, which checks the site and publishes `site/` to the Rootiest edge servers'
static web root. Caddy serves it at rootiest.com.

Until that cutover, Netlify still serves rootiest.com from the GitHub mirror; `netlify.toml` limits it
to `site/`. Delete `netlify.toml` once rootiest.com points at the Rootiest edges.

## Social preview image

`site/img/banner.png` (1200×630, used for `og:image`) is rendered from `scripts/banner.html`.
It is always Catppuccin Mocha, since link previews can't follow the viewer's light/dark mode.
The glows are not CSS gradients: `scripts/banner-bg.py` computes them and dithers them into
`scripts/banner-bg.png`, because browser gradients band visibly on dark colours.
After editing either file, re-render with Firefox and numpy installed:

```sh
python3 scripts/render-banner.py
```

When the image changes, bump the `?v=` number in `OG_IMAGE` in `scripts/sitegen/config.py` and
rebuild, so Discord and other sites fetch the new one instead of their cached copy.
